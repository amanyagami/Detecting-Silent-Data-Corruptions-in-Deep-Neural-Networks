01 — the problem

01Why it matters

A stray cosmic ray or a worn-out chip can flip a bit inside a running model. It doesn't crash — it just quietly changes the answer. In a self-driving car or a diagnostic scan, nothing downstream double-checks that.

A from-scratch reproduction of Dr. DNA (ASPLOS '24, Meta & Villanova) — no public code existed for the paper. This page covers one detection path (ResNet-18/CIFAR-10, single bit-flip) out of the paper's 10 models × 5 datasets × 4 error models.

03 — the fault

03What a "fault" actually is

Single bit, one neuron

The injector flips one bit in one neuron's activation — the closest software model of a real hardware glitch.

Built on PyTorchFI, with a custom targeting function for reproducible injection sites.

src/utils/customFI_methods.py

# flip one bit, one neuron
def random_neuron_single_bit_inj(
  pfi, layer, fi_c, fi_h, fi_w
):
  batch = random_batch_element(pfi)
  return pfi.declare_neuron_fi(
    dim1=[fi_c], dim2=[fi_h], dim3=[fi_w],
    function=pfi.single_bit_flip_signed
  )
04 — run it live

04The real model, in your browser

No server, no simulation. ResNet-18 exported to ONNX, split at the layer1→layer2 boundary, running on-device via WebAssembly. Pick a real CIFAR-10 image, and the fault button flips one real IEEE-754 bit in the real activation tensor before continuing the real forward pass — the exact same τ1/τ2/τ3 formula then scores it.
